O que é

Bibliodaurea é um software web que visa facilitar o registro de empréstimos de
livros da biblioteca na escola Luiz D'Áurea. O usuário poderá utilizar diversas
ferramentas que contribuem para o tratamento de cada livro, aluno e integridade da
biblioteca.
